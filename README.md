# Spotcha
Vibe, talk, hang out. Spotcha is a discord/Spotify like platform, where you talk to friends, and hangout, using ScratchAuth.
## Find the penguin mod project
the penguin mod project is at https://projects.penguinmod.com/9849690212
## AGE LIMITS
15+ or older - you get access to music and spotchaChat.
12-13 - you get access to music.
5 and younger - access to nothing.
